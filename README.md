# CarHub Frontend

A modern car rental and sales platform built with React and Tailwind CSS.

## Features
- 🚗 Browse vehicles for sale and rent
- 🔍 Advanced search and filters
- 🌓 Dark/Light mode toggle
- 📱 Fully responsive design
- 🔐 User authentication
- 📅 Online booking system
- 💳 M-Pesa integration ready

## Setup
1. Clone repository
2. Run `npm install`
3. Create `.env` file with API URL
4. Run `npm start`

## Environment Variables
- `REACT_APP_API_URL`: Backend API URL
- `REACT_APP_MPESA_CALLBACK_URL`: M-Pesa payment callback

## Tech Stack
- React 18
- Tailwind CSS
- React Router v6
- Axios
